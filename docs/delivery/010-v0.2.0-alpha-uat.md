# v0.2.0-alpha — User Acceptance Test Plan

**Executed:** 2026-08-02 (closed-loop agent)  
**User guide:** Ch.1–2 (`docs/user-guide/01-getting-started.md`, `02-embedded-dev-ui.md`)  
**Automated pre-checks:** `pytest tests/e2e -q` (47 passed), `make test-e2e-smoke` (12 passed)

## Purpose

Validate the **foundation release**:

- Health / readiness / version / metrics endpoints
- Embedded dev UI (`/ui`) against live API routes
- Journeys / jobs / schedules / prompts API (in-memory engine)
- kube-operator image pipeline + cluster deploy
- User guide quick-start paths (local + port-forward)

## Out of scope (alpha)

- DynamoDB-backed production engine, Temporal workers, React SPA
- Playwright suite (optional P1 enhancement — UI P0 covered via API + static asset tests)
