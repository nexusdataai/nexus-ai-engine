# v0.2.0-beta — User Acceptance Test Plan

**Executed:** 2026-08-02 (closed-loop agent)  
**User guide:** Ch.3 (`docs/user-guide/03-journey-dsl-authoring.md`)  
**Automated pre-checks:** `pytest` 85 passed — [pytest-journey-dsl.log](./evidence/v0.2.0-beta/pytest-journey-dsl.log)

## Purpose

Validate the **Journey DSL release**:

- Pydantic models per `docs/spec/010-journey-dsl.md`
- Semantic validator + `POST /api/v1/journeys/validate`
- DSL → `ExecutionGraph` compiler (nexus-sre contract alignment)
- Versioned journey CRUD (`import`, `versions`, `export`, `clone`)
- Published-version immutability
- Plugin YAML migration CLI (`scripts/migrate-plugin-yaml.py`)
- User guide Ch.3 authoring walkthrough

## Out of scope (beta)

- Execution submit API (`POST /api/v1/executions`) — v0.2.0-rc1
- DynamoDB-backed DSL persistence (in-memory store only for beta)
- Tool registry strict mode in production
- Embedded UI validation badge (optional P2 — not blocking GA)
- Playwright UI suite (API + pytest cover P0)
