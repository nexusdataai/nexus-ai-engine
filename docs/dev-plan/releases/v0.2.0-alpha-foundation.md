# Release v0.2.0-alpha Foundation — Sprint Plan

## Purpose

Land **monorepo scaffold**, **Pydantic contracts**, **CI**, and **kube-operator
plumbing** while hardening the existing **embedded Journey UI** (v0.1). Establishes
the delivery pipeline every subsequent release uses.

Starting point: v0.1.0a1 library + embedded JSX + TransformationJobExecutor.

## Release window

- **Sprints:** 1 – 2
- **Dates:** 2026-08-04 → 2026-08-28
- **GA cut:** 2026-08-28 (end of Sprint 2)

## Scope

1. `backend/` layout; contracts package from specs
2. JSON Schema export for Journey DSL v1
3. CI: ruff, pytest, contract tests
4. kube-operator targets: `ai-engine-api`
5. Embedded UI: route parity, seed data polish
6. UAT `docs/delivery/010-v0.2.0-alpha-uat.md` executed
7. User guide Ch.1–2 published

## Non-goals

- Journey DSL compiler (v0.2.0-beta)
- ExecutionManager / FSM (v0.2.0-rc1)
- React SPA (v0.3.0)
- Tool SDK (v0.2.0-rc2)

## Sprint sequence

| # | Sprint | Goal | Exit |
|---|---|---|---|
| 01 | Contracts & monorepo | Pydantic contracts, backend/ move plan, CI | Contract gate |
| 02 | UI + operator + **α GA** | kube-operator, UAT α, user guide | v0.2.0-alpha exit |

## Exit criteria

| Criterion | Sprint | Verifier |
|---|---|---|
| Contracts export 13+ schemas | 1 | Backend lead |
| `make test` green on main | 1 | CI |
| `./bump-version.sh ai-engine-api patch --dry-run` works | 2 | Platform |
| Embedded UI serves `/ui` + journeys API 200 | 2 | Frontend |
| UAT P0 100%; cut `0.2.0-alpha` | 2 | PO |
| User guide Ch.1–2 merged | 2 | Docs |
