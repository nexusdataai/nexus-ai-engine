# Release v0.2.0-beta Journey DSL — Sprint Plan

## Purpose

Deliver **Journey DSL** as versioned Pydantic models, **semantic validator**,
and **DSL → ExecutionGraph compiler** per `docs/spec/010-journey-dsl.md`.
Journey CRUD API stores compiled graphs; no distributed execution yet.

## Release window

- **Sprints:** 3 – 4
- **Dates:** 2026-08-31 → 2026-09-25
- **GA cut:** 2026-09-25

## Scope

1. `contracts/journey_dsl.py` — full DSL model
2. `journeys/validator.py` — schema + semantic rules
3. `journeys/compiler.py` — DSL → ExecutionGraph (nexus-sre contract)
4. Journey service + REST CRUD (`/api/v1/journeys`)
5. Golden compile tests for O2C + 4 sample journeys
6. Plugin YAML migration script (dry-run)
7. UAT + user guide Ch.3

## Non-goals

- ExecutionManager runtime (rc1)
- Tool strict validation against live registry (rc2)
- DynamoDB journey store (optional in-memory + file; DynamoDB in v0.2.0)

## Sprint sequence

| # | Sprint | Goal | Exit |
|---|---|---|---|
| 03 | DSL models + validator | Pydantic DSL, validate API | Validator gate |
| 04 | Compiler + CRUD + **β GA** | Compile golden journeys, UAT β | v0.2.0-beta exit |

## Exit criteria

| Criterion | Sprint | Verifier |
|---|---|---|
| All `examples/journeys/*.yaml` compile | 4 | Backend |
| `POST /journeys/{id}/validate` returns errors for bad DSL | 3 | Backend |
| Journey version immutability enforced | 4 | Backend |
| UAT P0 100%; cut `0.2.0-beta` | 4 | PO |
| User guide Ch.3 (DSL authoring) | 4 | Docs |
