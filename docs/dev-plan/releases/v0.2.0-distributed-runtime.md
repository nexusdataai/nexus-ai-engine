# Release v0.2.0 Distributed Runtime — Sprint Plan

## Purpose

Production-grade **persistence** (DynamoDB + S3), **Temporal workers**, and
**Executions API + SSE** — many concurrent journey executions with crash recovery.

This is the **first production-capable** AI Engine release for operators.

## Release window

- **Sprints:** 9 – 10
- **Dates:** 2026-11-23 → 2026-12-18
- **GA cut:** 2026-12-18 (before holiday freeze)

## Scope

1. DynamoDB tables: journeys, executions, tools metadata, locks
2. S3: logs + reports buckets
3. `execution_repo.py` with optimistic concurrency
4. Temporal `RunExecutionWorkflow` + worker deployment
5. `/api/v1/executions` full lifecycle + SSE stream
6. Admission controller: global + per-journey concurrency limits
7. Migration: v0.1 jobs → executions
8. MCP `execution_tool`
9. Helm: api + workers (+ embedded UI)
10. UAT v0.2.0 + user guide Ch.6

## Non-goals

- React SPA (v0.3.0 — embedded UI still supported)
- nexus-backend Copilot decoupling (v1.0.0)
- 500-execution load test (v1.0.0)

## Sprint sequence

| # | Sprint | Goal | Exit |
|---|---|---|---|
| 09 | DynamoDB + S3 | Persistence, migration script | Store gate |
| 10 | Workers + API + **v0.2.0 GA** | 50 concurrent staging, UAT, cut | v0.2.0 exit |

## Exit criteria

| Criterion | Sprint | Verifier |
|---|---|---|
| Execution survives worker restart | 9 | Platform |
| 50 concurrent executions on 3 worker pods | 10 | SRE |
| SSE stream delivers step events < 2s | 10 | Backend |
| UAT P0 100%; cut `0.2.0` | 10 | PO |
| User guide Ch.6 | 10 | Docs |
