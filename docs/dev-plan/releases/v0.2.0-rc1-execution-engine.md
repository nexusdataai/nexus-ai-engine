# Release v0.2.0-rc1 Execution Engine — Sprint Plan

## Purpose

Implement **ExecutionManager**, **101-aligned FSM**, and **ToolDispatcher**
with **EmbeddedToolRegistry** (mock/local tools). Run compiled journeys
**in-process** end-to-end — foundation for distributed workers in v0.2.0.

## Release window

- **Sprints:** 5 – 6
- **Dates:** 2026-09-28 → 2026-10-23
- **GA cut:** 2026-10-23

## Scope

1. `executor/manager.py`, `engine.py`, `graph.py`
2. FSM: journey / stage / step states per `021`
3. Retry, approval, verification, rollback engines (minimal viable)
4. ToolDispatcher + EmbeddedToolRegistry
5. LegacyStageAdapter for existing BaseStage processors
6. In-memory execution store (DynamoDB deferred to v0.2.0)
7. UAT + user guide Ch.4

## Non-goals

- Temporal workers
- nexus-tool-sdk / ontology HTTP (rc2)
- React SPA
- Production Copilot decoupling (v1.0.0)

## Sprint sequence

| # | Sprint | Goal | Exit |
|---|---|---|---|
| 05 | FSM + ExecutionManager | Tick loop, state transitions | FSM gate |
| 06 | Dispatcher + bridge + **rc1 GA** | Mock tool runs, UAT rc1 | v0.2.0-rc1 exit |

## Exit criteria

| Criterion | Sprint | Verifier |
|---|---|---|
| FSM transition matrix tests pass | 5 | Executor lead |
| O2C journey runs in-process with mock tools | 6 | Executor lead |
| Legacy stage job still works via adapter | 6 | Backend |
| UAT P0 100%; cut `0.2.0-rc1` | 6 | PO |
| User guide Ch.4 (executions API preview) | 6 | Docs |
