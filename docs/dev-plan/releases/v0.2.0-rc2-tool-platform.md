# Release v0.2.0-rc2 Tool Platform — Sprint Plan

## Purpose

Deliver **local Tool Registry**, **`nexus-tool-sdk`**, **tool package publish
pipeline**, and **ontology VDL/Connector API** integration per specs **040**
and **041**. Migrate **O2C tools** to run in AI Engine calling ontology HTTP APIs.

## Release window

- **Sprints:** 7 – 8
- **Dates:** 2026-10-26 → 2026-11-20
- **GA cut:** 2026-11-20

## Scope

### AI Engine

1. `packages/nexus-tool-sdk/` — VdlClient, ConnectorClient, ToolRuntime
2. `Tool` base class (nexus-sre aligned)
3. `ToolRegistry` + `ToolDispatcher` with real packages
4. `POST /api/v1/tool-packages` publish API
5. `packages/tools-o2c/` migrated from nexus-backend
6. Compiler strict tool validation

### Ontology (nexus-backend transitional)

7. Promote `POST /api/v1/vdl/query`
8. `POST /api/v1/vdl/batch-query`
9. Unified `POST /api/v1/connectors/{id}/invoke`
10. Contract tests SDK ↔ OpenAPI

### Quality

11. UAT rc2 + user guide Ch.5

## Non-goals

- DynamoDB tool metadata (minimal in-memory + file; full DynamoDB v0.2.0)
- Temporal
- Journey Studio SPA
- Deprecate CopilotEngine.execute_plan (v1.0.0)

## Sprint sequence

| # | Sprint | Goal | Exit |
|---|---|---|---|
| 07 | tool-sdk + Tool base | SDK + registry skeleton | SDK gate |
| 08 | Packages + ontology + **rc2 GA** | O2C live against staging VDL, UAT | v0.2.0-rc2 exit |

## Exit criteria

| Criterion | Sprint | Verifier |
|---|---|---|
| O2C match tool calls staging VDL via HTTP | 8 | Tools lead |
| Publish tool package registers tools | 8 | Backend |
| Compiler rejects unknown tool_id | 8 | Backend |
| Ontology VDL + connector invoke APIs live | 8 | Ontology liaison |
| UAT P0 100%; cut `0.2.0-rc2` | 8 | PO |
| User guide Ch.5 | 8 | Docs |
