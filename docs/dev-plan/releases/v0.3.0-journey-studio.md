# Release v0.3.0 Journey Studio — Sprint Plan

## Purpose

Replace embedded JSX UI with **standalone React SPA** (Journey Studio) per
`docs/spec/070-ui-specification.md` — fleet dashboard, journey authoring,
live execution monitor with SSE, tools catalog.

## Release window

- **Sprints:** 11 – 12
- **Dates:** 2027-01-05 → 2027-01-30
- **GA cut:** 2027-01-30

## Scope

1. `frontend/` Vite + React 18 + TypeScript + Tailwind
2. Pages: Dashboard, Journeys, Journey Studio, Executions, Schedules, Tools
3. TanStack Query + EventSource SSE reconnect
4. ReactFlow execution graph
5. DSL editor (Monaco or YAML textarea v1)
6. Cognito JWT integration (ingress)
7. Separate `nexus-ai-engine-ui` image + Helm
8. UAT v0.3.0 + user guide Ch.7

## Non-goals

- Copilot / LLM authoring in UI (ontology platform)
- Write tools from UI (read-only catalog)
- nexus-backend full decoupling (v1.0.0)

## Sprint sequence

| # | Sprint | Goal | Exit |
|---|---|---|---|
| 11 | SPA shell + monitor | Dashboard, executions list/detail | UI gate 1 |
| 12 | Studio + tools + **v0.3.0 GA** | DSL editor, UAT, cut | v0.3.0 exit |

## Exit criteria

| Criterion | Sprint | Verifier |
|---|---|---|
| Operator submits journey via UI only | 12 | Frontend |
| Live SSE updates execution graph | 12 | Frontend |
| a11y AA on primary flows | 12 | QA |
| UAT P0 100%; cut `0.3.0` | 12 | PO |
| User guide Ch.7 with screenshots | 12 | Docs |
