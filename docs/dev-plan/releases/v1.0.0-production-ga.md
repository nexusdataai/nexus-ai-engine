# Release v1.0.0 Production GA — Sprint Plan

## Purpose

**Production hardening**: nexus-backend **Copilot decoupling** (submit executions
to AI Engine only), load testing (500 concurrent), security review, observability,
operator runbooks. Marks AI Engine as **shared platform** for all ontology domains.

## Release window

- **Sprints:** 13 – 14
- **Dates:** 2027-02-02 → 2027-02-26
- **GA cut:** 2027-02-26

## Scope

1. nexus-backend: CopilotEngine → `POST /executions` client; deprecate prod `execute_plan`
2. Feature flag `AI_ENGINE_EXECUTION_ENABLED` per tenant
3. Load test: 500 concurrent executions
4. Security: pen test, IAM least privilege, mTLS ontology ↔ engine
5. Grafana dashboards + alerts (SLO from spec 080)
6. Supply-chain + O2C reference journeys in prod
7. Full UAT v1.0.0 + admin guide Ch.8–9

## Non-goals

- New journey DSL features
- Neo4j / multi-region (future platform releases)
- Ontology service split (nexus-ontology repo) — can proceed in parallel

## Sprint sequence

| # | Sprint | Goal | Exit |
|---|---|---|---|
| 13 | Decouple + observability | Backend integration, dashboards | Integration gate |
| 14 | Load + security + **v1.0.0 GA** | UAT prod, cut `1.0.0` | v1.0.0 exit |

## Exit criteria

| Criterion | Sprint | Verifier |
|---|---|---|
| Copilot prod path uses AI Engine only | 13 | Backend + PO |
| 500 concurrent executions pass load test | 14 | SRE |
| Pen test sev1 = 0 | 14 | Security |
| SLO dashboards live | 13 | SRE |
| UAT P0 100%; cut `1.0.0` on prod | 14 | PO |
| Admin guide + troubleshooting complete | 14 | Docs |
